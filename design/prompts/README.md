# Промпты для генерации фотографий

Библиотека промптов под визуальный язык из [`../design.mdc`](../design.mdc).

## Как пользоваться

1. Открой нужный файл по типу изображения (см. таблицу ниже).
2. Возьми промпт, подставь свои переменные — они помечены `{ФИГУРНЫМИ СКОБКАМИ}`.
3. Приклей общий суффикс качества из [`00-style-core.md`](00-style-core.md).
4. Прогони негативный промпт оттуда же.

**Промпты написаны по-английски намеренно** — все генераторы (Midjourney, Flux, Ideogram,
Nano Banana, Seedream, DALL·E) обучены преимущественно на английских подписях и дают на
нём заметно более точный результат. Описания и комментарии — по-русски.

## Размеры под макет

| Где используется | Пропорция | Рендер |
|---|---|---|
| Hero, обложка раздела | 16:9 | 2560×1440 |
| Карточка портфолио | 4:5 | 1200×1500 |
| Карточка новости | 3:2 | 1500×1000 |
| Квадрат в подборке | 1:1 | 1400×1400 |
| Аватар | 1:1 | 400×400 |
| Широкий баннер | 21:9 | 2560×1100 |

Генерь с запасом 1.5–2× от размера в макете — под retina.

## Куда складывать результат

```
public/images/
  hero/        главный экран и обложки
  portfolio/   работы и кейсы
  team/        команда
  editorial/   блог и новости
  avatars/     аватары
```

Перед выкладкой: конвертировать в WebP (качество 82), делать по 2 размера
(1x / 2x), прописывать `width`/`height` в разметке.

## Чек-лист перед тем, как взять кадр в макет

- [ ] Внутри изображения нет текста, логотипов, водяных знаков
- [ ] Руки, глаза, украшения — без артефактов (проверить при 100% зуме)
- [ ] Кадр читается в маленьком размере (сожми до 300px — герой ещё виден?)
- [ ] Цвет не спорит с соседними карточками в том же гриде
- [ ] Есть место под чип категории в левом верхнем углу
- [ ] Кадр не «уезжает» при кропе в 4:5 и 1:1
