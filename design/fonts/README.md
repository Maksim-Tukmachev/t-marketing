# Шрифты

Все файлы `.woff2` скачаны с Google Fonts, включая кириллические подмножества.
CSS в каждой папке уже переписан на локальные пути — работает офлайн, без запросов
к `fonts.googleapis.com`.

**Открой [`preview.html`](preview.html) в браузере** — там весь набор на русском,
во всех размерах и начертаниях. Смотреть в браузере, не в редакторе.

---

## Что чем заменено

| Роль | В референсе | Взяли | Лицензия |
|---|---|---|---|
| Display | Druk Condensed (Commercial Type) | **Fira Sans Extra Condensed** | OFL, бесплатно |
| Body / UI | PP Neue Montreal / Aeonik | **Onest** | OFL, бесплатно |
| Запасной body | — | **Inter** | OFL, бесплатно |
| Запасной display | — | **Oswald** | OFL, бесплатно |

## Почему именно эти

**Fira Sans Extra Condensed** — практически единственный бесплатный сверхузкий
гротеск с полноценной кириллицей. Проверено: `Anton`, `Bebas Neue`, `Archivo`,
`Archivo Black` кириллицы **не содержат**, хотя их постоянно советуют для такой
типографики. Fira по массе чуть легче Druk, но пропорции и характер близкие.

**Onest** — гротеск, спроектированный сразу от кириллицы, а не адаптированный.
Из бесплатных ближе всего к Neue Montreal: та же слегка геометричная основа,
одноэтажная `g`, спокойные окончания. На русском выглядит естественнее Inter.

**Inter** и **Oswald** лежат рядом как запасные — если Onest покажется слишком
мягким, а Fira недостаточно плакатной, поменяй одну строку в `tokens.css`.

## Подключение

Уже прописано в [`../tokens.css`](../tokens.css):

```css
@import url("./fonts/fira-sans-extra-condensed/fira-sans-extra-condensed.css");
@import url("./fonts/onest/onest.css");
```

Замена на альтернативы — одна переменная:

```css
--f-display: "Oswald", sans-serif;   /* вместо Fira */
--f-body:    "Inter", sans-serif;    /* вместо Onest */
```

## Что проверить на русском

Узкие шрифты хуже переносят кириллицу, чем латиницу. Смотреть на:

- **`Ж Ш Щ Ф Ю М Ы`** — самые широкие знаки. В Extra Condensed они выбиваются
  из ритма строки. Если строка рвётся — уменьшай трекинг, а не кегль.
- **Длина строки.** Русский текст длиннее английского примерно на 15%.
  Заголовок, который помещался в две строки на английском, на русском займёт три.
- **CAPS-набор.** В кириллице прописные плотнее латинских: ставь
  `letter-spacing: -0.01em`, иначе заголовок выглядит разреженным.
- **Цифры.** У Onest табличные цифры включаются через
  `font-variant-numeric: tabular-nums` — обязательно для таблиц и счётчиков.

## Если появится бюджет

Точное попадание в референс дадут платные:

| Шрифт | Роль | Ориентир |
|---|---|---|
| **Druk Cyrillic** (Commercial Type) | Display | Ровно то, что в референсе |
| **Suisse Int'l Cyrillic** (Swiss Typefaces) | Body | Эталон швейцарского гротеска |
| **TT Firs Neue Condensed** (TypeType) | Display | Заметно дешевле Druk |
| **Involve** / **Formular** (Brownfox) | Body | Хорошая русская альтернатива |

## Вес и производительность

| Семейство | Файлов | Размер |
|---|---|---|
| Fira Sans Extra Condensed | 21 | 468 КБ |
| Onest | 4 | 80 КБ |
| Inter | 7 | 240 КБ |
| Oswald | 5 | 88 КБ |

Файлы разбиты по подмножествам (`latin`, `latin-ext`, `cyrillic`, `cyrillic-ext`,
`greek`), браузер грузит только нужные — на русскоязычном сайте это `latin` +
`cyrillic`, порядка 40–60 КБ на семейство.

В `<head>` имеет смысл добавить preload для того, что видно сразу:

```html
<link rel="preload" as="font" type="font/woff2" crossorigin
      href="/design/fonts/onest/<файл-cyrillic>.woff2">
```

Неиспользуемые семейства (`inter/`, `oswald/`) перед продом удали — они лежат
здесь только как варианты для выбора.
